## Overview

This is a **Symfony 8.0 demo application** that showcases integration with the MatesOfMate ecosystem of Mate extensions. It serves as both a testing ground and reference implementation for MatesOfMate extensions.

**Purpose**: Demonstrate and test the Mate tools from composer-extension, phpunit-extension, phpstan-extension, rector-extension, and Symfony Mate.

## Commands

### Testing

```bash
vendor/bin/phpunit                              # Run all tests
vendor/bin/phpunit tests/CalculatorTest.php     # Run specific test file
vendor/bin/phpunit --filter testAdd             # Run tests matching pattern
```

### Static Analysis

```bash
vendor/bin/phpstan analyse                      # Run PHPStan at level max
vendor/bin/phpstan analyse src/                 # Analyze specific directory
```

### Refactoring

```bash
vendor/bin/rector process --dry-run              # Preview refactorings
vendor/bin/rector process                        # Apply refactorings
vendor/bin/rector process src/                   # Limit to a directory
```

### Mate Extensions

```bash
vendor/bin/mate discover                        # Discover/register extensions and install skills
vendor/bin/mate tools:list                      # List available tools
vendor/bin/mate tools:inspect phpunit-run       # Show a tool's parameters
vendor/bin/mate tools:call phpunit-run --mode=summary
vendor/bin/mate resources:read phpstan://config
```

### Dependencies

```bash
composer install                                # Install all dependencies
```

## Mate Integration

Mate tools are called through `vendor/bin/mate tools:call`. Prefer them over the raw CLI commands:

| Instead of...                    | Use Mate tool                                       |
|----------------------------------|-----------------------------------------------------|
| `vendor/bin/phpunit`             | `phpunit-run`                                       |
| `vendor/bin/phpunit tests/X.php` | `phpunit-run --file=tests/X.php`                    |
| `vendor/bin/phpstan analyse`     | `phpstan-analyse`                                   |
| `composer why <package>`         | `composer-explain --package=<package>`              |
| `vendor/bin/rector --dry-run`    | `rector-preview`                                    |
| `vendor/bin/rector process`      | `rector-apply`                                      |
| checking the Rector setup        | `rector-inspect`                                    |

Mate tools provide token-optimized output designed for AI consumption.

## Architecture

**Minimal Microkernel**: Uses Symfony's microkernel pattern without full-stack bloat.

**Extension Discovery Flow**:
1. `composer.json` defines path repositories pointing to monorepo extensions
2. `mate/extensions.php` lists enabled extensions (managed by `mate discover`)
3. `mate/config.php` provides custom service configuration
4. `mate discover` regenerates `mate/AGENT_INSTRUCTIONS.md` and installs skills into `.agents/skills` and `.claude/skills`

**Custom Tools**: Place custom tools in `mate/src/` (PSR-4: `App\Mate\`)

## Intentional Quality Issues

The demo contains **deliberate bugs and quality issues** for testing analysis tools:

**Calculator.php**:
- `problematicMethod()` - Undefined variable, unreachable code
- `typeIssueMethod()` - Wrong return type (returns string as int)
- `unusedParamMethod()` - Unused parameter

**CalculatorTest.php**:
- `testAddFailing()` - Intentionally wrong assertion (expects 10, result is 5)
- `testDivideErroring()` - Unhandled exception
- `testPhpstanErrors()` - Calls non-existent method, wrong parameter types

These are test subjects for PHPStan and PHPUnit analysis - do not "fix" them unless specifically asked.

## Configuration

| File | Purpose |
|------|---------|
| `phpstan.neon` | PHPStan at level `max` analyzing `src/` and `tests/` |
| `phpunit.dist.xml` | PHPUnit with strict mode (fails on deprecation/notice/warning) |
| `rector.php` | Rector with PHP 8.4 level set plus code quality, dead code, early return, type declaration and PHPUnit sets |
| `mate/extensions.php` | Extension registry (auto-generated by `mate discover`) |
